Paris Metro Game v0.9.1b

NEW FEATURES
- Zero-score streaks are now saved and displayed in score history.

INTERFACE IMPROVEMENTS
- Replaced keyboard-based countdown duration entry with a dedicated minutes-and-seconds picker.
- Countdown duration can only be selected with the picker; no keyboard-entry option is shown.
- The countdown picker uses the application's blue Material theme for its controls.
- Pressing Android's Back navigation button during an active game now opens a confirmation dialog with Yes and No actions.
- Choosing Yes abandons the current game and returns to the main menu; choosing No resumes the game.
